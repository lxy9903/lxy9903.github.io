数据库对比

常见数据库访问框架 / 技术

框架 / 技术 类型 数据库类型 SQL 控制 ORM 支持 开发效率 灵活性 事务管理 使用场景
JDBC / Spring JDBC 底层 / 封装 关系型 高（手写 SQL） ❌ 中 高 支持声明式事务 精细控制 SQL、轻量 CRUD
JPA（Hibernate / Spring Data JPA） ORM 关系型 低（自动生成 SQL，可自定义 JPQL / Native SQL） ✅ 完整 ORM 高 中 支持声明式事务 CRUD 多、快速开发企业应用
MyBatis / MyBatis-Plus 半 ORM 关系型 高（手写 SQL，可自动 CRUD 增强） ✅ 映射支持 高 高 支持声明式事务 SQL 可控，复杂查询、多表操作
R2DBC 响应式 SQL 关系型 高（手写 SQL / SQL 构建器） ❌ 中 高 支持声明式事务 高并发、响应式数据库访问
Spring Data MongoDB NoSQL MongoDB 中（Template / Repository） ✅ 映射到文档对象 高 中 支持事务（MongoDB 4.x+） 文档数据库操作，类 JPA 风格
Spring Data Redis NoSQL Redis 高（RedisTemplate / 命令） ❌ 高 中 支持事务（MULTI / EXEC） 缓存、分布式锁、消息队列
Spring Data Elasticsearch NoSQL Elasticsearch 中（Template / Repository） ✅ 映射到对象 高 中 支持轻量事务 搜索 / 文档检索操作
