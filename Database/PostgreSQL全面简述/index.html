PostgreSQL全面简述

1. PostgreSQL 是什么？

  • 一个 开源的、企业级、强一致性 的 关系型数据库（RDBMS）
  • 以 性能、可扩展性、SQL 能力强 著称
  • 被称为 “世界上最先进的开源数据库”

可以视为 Oracle 的开源替代品。

2. PostgreSQL 用来做什么？

PostgreSQL 的能力覆盖范围非常广：

🔹传统应用

  • OLTP 系统（金融、电商、ERP、支付）
  • 强事务一致性、高并发场景

🔹 复杂分析

  • 复杂 SQL、分组、聚合、窗口函数
  • 支持多表 Join，优化器比 MySQL 强

🔹 地理信息系统（GIS）

  • 配合 PostGIS 实现行业标配（地图、导航、物流）

🔹 JSONB 文档数据库

  • 既支持关系结构，又支持文档结构（NoSQL）

🔹 大模型 & 向量数据库（AI）

  • 配合 pgvector → 直接成为向量数据库
  • 构建 RAG（检索增强生成）非常方便

1）关系型结构化数据

表、行、列、索引：传统业务的标准形态。

4. PostgreSQL 怎样存储数据？

PostgreSQL 数据存储结构如下：

1）行式存储（Heap Table）

数据以 表文件（heap file） 存储在磁盘中：

每个数据页默认 8KB：

2）MVCC（多版本并发控制）

更新不会覆盖旧数据，而是创建新版本：

  • xmin 插入事务
  • xmax 删除事务

更新过程：

因此：

  • 高并发性能强
  • 不需要加锁即可读一致快照

3）WAL（Write-Ahead-Log）

全部改动先写入 WAL，再写入磁盘
→ 保证数据安全。

4）索引存储

支持多种索引类型：

  • B-Tree（默认）
  • GIN（JSONB、全文搜索）
  • GiST（模糊匹配）
  • BRIN（大表范围索引）
  • Vector index（pgvector HNSW/IVFFlat）

PostgreSQL 的扩展性极强，ES/Redis/MySQL 都无法比。

5. 为什么 PostgreSQL 在 AI 时代大量应用？

因为 PostgreSQL 正好符合 AI 场景的三大需求：

① 可以存向量（embedding）

借助 pgvector，PostgreSQL 秒变向量数据库，并且是目前最主流方案：

  • 支持 HNSW、IVFFlat 等向量索引
  • 可以与业务数据在同一张表
  • 支持强事务、SQL、JOIN

很多 AI 产品（比如 Supabase、Prisma、OpenAI 官方示例）都直接使用 pgvector。

② JSONB 自然适合存模型内容 / 配置 / Prompt

例如：

  • 示例对话
  • Prompt 模版
  • 模型配置
  • agent 工作流
  • 功能插件配置

比 MongoDB 更强，更易用。

③ PostgreSQL 是企业级数据库，可以做主业 + AI 一体化

用一个数据库就能：

  • 存用户数据
  • 存业务数据
  • 存 AI 索引
  • 存模型配置、日志
  • 做全文搜索（pg_trgm）
  • 做向量搜索（pgvector）

统一性强 → 简化系统复杂度。

因此，被称为「AI 时代最好的默认数据库」。

什么时候用 PostgreSQL？

  • 强一致性
  • 复杂 SQL、OLTP 场景
  • 需要事务、JOIN、写安全
  • 需要向量数据库（pgvector）
  • 数据结构复杂：JSON + 结构化数据混合
  • 单体系统或中型系统
