MongoDB基本概念

1️⃣ MongoDB 基本概念

  • MongoDB 是一个面向文档的 NoSQL 数据库，使用 BSON（Binary JSON） 存储数据。
  • 支持：
    • 灵活的 schema：文档结构可变，不像关系型数据库固定表结构。
    • 高可用性：通过 Replica Set 实现主从复制。
    • 可扩展性：通过 Sharding 实现水平扩展。
  • 核心特点：
    • 文档存储（Document-oriented）
    • 键值对数据模型
    • 内置索引和聚合功能
    • 强大的查询和统计能力

  • 基本类型：String, Number, Boolean, Date, Null

7️⃣ 数据库设计要点

  1. 合理使用嵌套文档 vs 引用：
    • 小量数据嵌套，减少 join。
    • 大量或多对多关系用引用。
  2. 索引优化：
    • 常用查询字段建立索引。
    • 避免过多索引影响写入性能。
  3. 文档大小限制：
    • 单文档最大 16MB。
  4. 分片设计：
    • 数据量大时考虑 Sharding。
    • 选择高基数字段作为分片键。

8️⃣ 副本集与高可用

  • Replica Set：一个主节点 + 多个从节点。
  • 特点：
    • 自动选举主节点。
    • 主节点写入，副本节点同步。
    • 保证数据高可用。

9️⃣ Sharding（水平扩展）

  • 将集合的数据分布在多个节点。
  • 组成：
    • Shard：存储数据
    • Config Server：存储元数据
    • Mongos：路由查询请求
  • 选择分片键要注意：
    • 高基数
    • 查询常用字段
    • 均匀分布
