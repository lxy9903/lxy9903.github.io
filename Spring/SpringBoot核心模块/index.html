Spring Boot 核心模块

1. SpringApplication 启动模块

  • 功能：
    • 应用入口，负责启动 Spring 容器
    • 初始化 Environment（配置）、ApplicationContext（IOC 容器）
    • 加载自动装配类、注册监听器、启动内嵌容器（Web 应用）
  • 核心类：
    • SpringApplication
    • SpringApplicationRunListeners
    • ApplicationContextInitializer
  • 图示：

2. 自动配置（Auto-Configuration）模块

  • 功能：
    • 根据类路径、Bean 定义、配置文件自动注册 Bean
    • 避免手动配置，快速接入模块
  • 核心原理：
    1. @EnableAutoConfiguration 注解
    2. SpringFactoriesLoader 加载 META-INF/spring.factories 配置的自动配置类
    3. @ConditionalOnClass, @ConditionalOnMissingBean 判断条件
  • 核心类：
    • EnableAutoConfigurationImportSelector
  • 图示：

3. IOC / DI 模块

  • 功能：
    • 控制反转（Inversion of Control）+ 依赖注入（Dependency Injection）
    • 管理 Bean 生命周期
  • 核心注解：
    • @Component, @Service, @Repository, @Controller
    • @Autowired, @Qualifier, @Resource
  • Bean 生命周期：
    1. 扫描 BeanDefinition
    2. 注册到 BeanFactory
    3. 实例化 Bean
    4. 注入依赖
    5. 初始化及后置处理
  • 图示：

4. AOP 模块

  • 功能：
    • 解耦横切关注点（日志、事务、权限）
  • 核心注解：
    • @Aspect, @Before, @After, @Around
    • @EnableAspectJAutoProxy
  • 实现方式：
    • JDK 动态代理（接口代理）
    • CGLIB 动态代理（类代理）
  • 图示：

5. Web 模块

  • 功能：
    • 内嵌 Web 容器（Tomcat / Jetty / Undertow）
    • 请求处理流程（DispatcherServlet → HandlerMapping → Controller → View）
  • 核心类：
    • DispatcherServlet
    • WebMvcAutoConfiguration
    • ServletWebServerFactoryAutoConfiguration
  • 请求拦截：
    • Filter：Servlet 层统一拦截
    • Interceptor：Spring MVC 层 Controller 前后逻辑处理
  • 图示：

6. Starter 系列模块

  • 功能：
    • 统一依赖管理，快速引入各种功能模块
    • 自动加载相关配置（Auto-Configuration）
  • 常用 Starter：
    • 核心：spring-boot-starter
    • Web：spring-boot-starter-web
    • 数据访问：spring-boot-starter-data-jpa, spring-boot-starter-jdbc
    • 安全：spring-boot-starter-security
    • 测试：spring-boot-starter-test
    • 监控：spring-boot-starter-actuator
  • 图示：

7. 外部配置模块

  • 功能：
    • 配置文件管理（application.properties / application.yml）
    • 支持多环境配置、配置优先级、类型绑定
  • 核心注解：
    • @ConfigurationProperties, @Value
  • 核心类：
    • Environment, PropertySourcesPropertyResolver

8. Actuator 模块

  • 功能：
    • 提供生产级监控接口
    • 健康检查、指标收集、日志管理、端点信息
  • 核心类：
    • HealthEndpoint, MetricsEndpoint, InfoEndpoint
  • 核心特性：
    • /actuator/health, /actuator/metrics 等 REST 接口
