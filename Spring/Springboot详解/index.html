一、Spring Boot 简要介绍

  • Spring Boot 是基于 Spring 的快速开发框架，目标是简化 Spring 应用的配置和部署。
  • 核心特点：
    1. 自动配置（Auto-Configuration）：减少 XML 配置或注解配置。
    2. Starter 依赖：统一依赖管理，一步引入所需功能。
    3. 嵌入式容器：如 Tomcat、Jetty，无需外部部署。
    4. 生产级特性：如 Actuator 监控、健康检查、指标收集。

二、核心知识点

1. IOC / DI 原理 ⭐️

概念：

  • IOC（Inversion of Control，控制反转）：对象的创建、管理交给容器，而不是程序主动创建。
  • DI（Dependency Injection，依赖注入）：将对象依赖通过容器注入到类中。

核心注解：

  • @Component、@Service、@Repository、@Controller
  • @Autowired / @Qualifier / @Resource

核心类 / 源码分析：

  1. BeanFactory / ApplicationContext

    • BeanFactory：基础接口，负责 Bean 的实例化和管理。
    • ApplicationContext：BeanFactory 的增强，支持事件、国际化等。

  2. 注解解析

    • ClassPathBeanDefinitionScanner 扫描注解类。
    • AutowiredAnnotationBeanPostProcessor 处理 @Autowired 注入。

  3. 对象创建流程（简化）

2. AOP 原理 + 动态代理 ⭐️

概念：

  • AOP（Aspect Oriented Programming）：面向切面编程，用于解耦横切关注点（如日志、事务）。
  • Spring AOP 基于代理模式实现：
    • JDK 动态代理：接口代理
    • CGLIB：类代理（没有接口）

核心注解：

  • @Aspect
  • @Before / @After / @Around
  • @EnableAspectJAutoProxy

核心源码分析：

  1. 代理生成

    • AnnotationAwareAspectJAutoProxyCreator -> AbstractAutoProxyCreator
    • 根据切面条件生成代理对象

  2. 执行流程

3. 自动装配 + Starter 机制

自动装配（Auto-Configuration）

  • 概念：根据 classpath、bean 定义等条件，自动配置 Spring Bean。
  • 核心注解
    • @EnableAutoConfiguration
    • @ConditionalOnClass, @ConditionalOnMissingBean 等条件注解
  • 源码分析
    • SpringFactoriesLoader 加载 META-INF/spring.factories 中的配置
    • 根据条件动态注册 Bean

Starter 机制

  • 概念：通过依赖引入，自动添加所需库和配置（如 spring-boot-starter-web）
  • 实现：
    • pom.xml 中引入 starter
    • starter 的 spring.factories 提供自动配置类
    • 应用启动时自动加载

4. Filter / Interceptor

Filter

  • 概念：Servlet 规范的过滤器，用于请求预处理/响应处理

  • 使用

    • @WebFilter 或 FilterRegistrationBean

  • 生命周期：

Interceptor

  • 概念：Spring MVC 层面的拦截器，处理 Controller 请求

  • 核心类

    • HandlerInterceptor（preHandle / postHandle / afterCompletion）
    • WebMvcConfigurer 注册 interceptor

  • 区别

    Filter Interceptor
    层级 Servlet 层 Spring MVC 层
    生命周期 容器启动即生效 DispatcherServlet 请求周期
    用途 统一处理请求/响应 Controller 前后逻辑处理
