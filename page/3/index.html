MongoDB基本概念

1️⃣ MongoDB 基本概念 MongoDB 是一个面向文档的 NoSQL 数据库，使用 BSON（Binary JSON） 存储数据。 支持： 灵活的 schema：文档结构可变，不像关系型数据库固定表结构。 高可用性：通过 Replica Set 实现主从复制。 可扩展性：通过 Sharding 实现水平扩展。 核心特点： 文档存储（Document-oriented） 键值对数据模型
