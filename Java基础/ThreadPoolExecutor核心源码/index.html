一、ThreadPoolExecutor 核心结构

一句话：

ThreadPoolExecutor = 状态机（ctl）+ 任务调度（execute）+ 线程管理（Worker）

二、execute() —— 线程池真正入口

1️⃣ execute() 源码

2️⃣ execute() 行为流程图（✅可解析）

3️⃣ execute() 设计思想（面试重点）

阶段 目的
先扩 core 保证最低并发能力
再入队 平滑流量，削峰
再扩 max 应对短期高峰
最后拒绝 系统自我保护

三、addWorker() —— 创建线程的核心方法

1️⃣ addWorker() 源码（关键逻辑版）

2️⃣ addWorker() 做了什么？

拆解为 4 步：

  1. 检查线程池状态
  2. CAS 增加 workerCount
  3. 创建 Worker
  4. 启动 Thread
